# Meshwar (مشوار) 🚗🇪🇬

**Meshwar** is an Egyptian transit cost calculator designed to help users find the cheapest and most efficient way to travel from Point A to Point B across Egypt. Whether navigating public transport, microbuses, metro, or ride-hailing services, Meshwar helps you optimize your daily commute budget.

---

## ✨ Features

- **Route Cost Comparison:** Calculate and compare estimated travel costs across various transportation options in Egypt.
- **Cheapest Path Finder:** Intelligent algorithm to highlight the most budget-friendly route combination.
- **Cross-Platform UI:** Clean and modern user interface powered by [Flet](https://flet.dev/) (Flutter + Python).
- **Automated Builds:** CI/CD pipeline integrated via GitHub Actions to generate Android APK releases automatically on every push.

---

## 📱 Mobile App (Android APK)

You don't need to build the project locally! You can grab the ready-to-install release APK directly from our GitHub Actions CI pipeline:

1. Go to the **[Actions Tab](https://github.com/ahmedomardev/Meshwar/actions)** on GitHub.
2. Select the latest successful workflow run.
3. Scroll down to **Artifacts** and download **`Meshwar-Release-APK`**.

---

## 🛠️ Tech Stack

- **UI Framework:** [Flet](https://flet.dev/)
- **Core Language:** Python 3.12
- **Mobile Engine:** Flutter / Serious Python
- **CI/CD:** GitHub Actions (Automated Linux Android Build Agent)
